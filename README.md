# machine-learning-zoomcamp

## Introduction to Machine Learning concepts

### Introduction to numpy, panda
It teaches about the python libraries readily available for performing basic python numberical operations. Such as numerical data, numerical arrays, working with arrays, processing tabular data etc. The main abstraction there is the DataFrame generated via a csv file and performing operations on the DataFrame object.

### Linear algebra
It taught about the basics of linear algebra, the python libraries to perform algebraic operations. Namely vector multiplication, matrix multiplication, transpose, inversion etc.
